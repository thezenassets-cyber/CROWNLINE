# Implementation status

Last updated: 27 October 2026.

This file is the source of truth for what exists. A feature is listed as
**implemented** only if the code exists and has been exercised. "Tested" means
covered by the automated suite; "manually checked" means verified in a browser
during development but not covered by an automated test.

## Verification

- `npm run typecheck` — passes with no errors.
- `npm test` — 45 tests, 45 passing, 0 failing (Node test runner; unit,
  integration against PGlite, and HTTP tests against a running app instance).
- Manual browser checks of the public site and admin console, including a 375 px
  mobile width for the calculator and tracking pages.

Not yet done: automated browser (end-to-end) tests, accessibility audit with
assistive technology, load testing, independent security testing.

## Milestone 1 — Foundation, public site, tracking and operations console

### Implemented and tested

| Area | What is covered |
| --- | --- |
| Configuration | Validated environment; production refuses missing secrets, embedded DB, non-HTTPS URL |
| Pricing engine | Unit conversion, dimensional and billable weight (per-package and per-shipment rounding), ocean LCL, minimums, surcharges, fuel, optional cover, limits, rate card validation, disabled mode |
| Progress engine | Highest-milestone progress, no regression on late events, void corrections, exceptions excluded, 100% only with delivery, domestic step filtering |
| Tracking codes | Format, check character catches all single-character typos, normalisation, uniqueness, keyed hashing |
| Permissions | Role matrix, role-assignment rules, no self-escalation, sessions revoked on role change |
| Shipments | Create (idempotent, permission-checked, booking event), events, dedupe, future-time rejection, void, exceptions, delivery evidence, cancel and archive rules, archived read-only |
| Tracking credentials | Issue (shown once, never stored in plain text), lookup, revoke (immediate), expiry |
| Authentication | Generic failures, lockout, CSRF on sign-in, forced password change, safe redirects, logout invalidates the session |
| Audit | Entries written for actions; append-only enforced by the database |
| HTTP security | CSP and security headers, no inline scripts/styles, no cookies on public pages, source/legacy/env files not served, cross-site POST rejected, admin CSRF |
| Public pages | Calculator (demo label, billable weight, validation errors), quote request (server-side pricing, idempotent, consent), contact form (honeypot), branded 404 |
| Public tracking | Shows only public fields, `no-store` and `no-referrer`, revoked code indistinguishable from an unknown code |
| Admin over HTTP | Full lifecycle (create → issue code → public lookup → event → delivery rule → PDF → revoke → audit order); operator and auditor blocked from restricted actions |
| Documents | Shipment summary PDF generated for an authorised user (returns a PDF) |

### Implemented, manually checked (no dedicated automated test)

- Public pages: home, services index and seven service pages, how it works,
  about, FAQ, terms, privacy, cookies, claims, `robots.txt`, `sitemap.xml`.
- Responsive layout (desktop, tablet, 375 px mobile), reduced-motion and print styles.
- Admin: overview metrics with date range, shipment list filters and pagination,
  quote request list/detail/status, quote estimate PDF, contact messages,
  team management (create, role, disable/enable, password reset), audit log
  filters, settings page (integrations shown as "Not configured").
- Estimated delivery date (staff estimate) set/clear.
- Demo seed script with three fictional shipments.
- WebP image pipeline and self-hosted fonts.

## Roadmap

1. **Foundation and operations (this milestone)** — done as described above.
2. **Hardening** — end-to-end browser tests, accessibility audit, MFA for staff,
   shared rate limiter, retention jobs, security contact, legal review.
3. **Carrier integration** — first carrier adapter in sandbox, webhook intake,
   carrier tracking identifiers, honest "last synced" display.
4. **Notifications** — email provider, templates for key milestones, delivery log.
5. **Formal quotes and invoicing** — quote line items, PDF quote, invoice records.
6. **Payments** — hosted checkout, verified webhooks, receipts.
7. **Business portal** — organisation accounts, shipment lists scoped to the
   organisation, bulk tracking.
8. **Operations at scale** — owner-managed pricing rules with approval,
   reporting, document uploads with scanning.
